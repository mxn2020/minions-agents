# Minions Agents

Agent definitions, runs, traces, and approval requests for the agent fleet

## Overview

This project is part of the [Minions ecosystem](https://github.com/mxn2020/minions) and provides:

- **TypeScript SDK** (`@minions-agents/sdk`) — Core library for Node.js
- **Python SDK** (`minions-agents`) — Python bindings
- **CLI Tool** (`@minions-agents/cli`) — Command-line interface
- **Web App** — Interactive playground at [agents.minions.wtf](https://agents.minions.wtf)
