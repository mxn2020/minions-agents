---
title: Installation
description: Install Minions Agents packages
---

## TypeScript / Node.js

```bash
npm install @minions-agents/sdk minions-sdk
```

## Python

```bash
pip install minions-agents
```

## CLI

```bash
npm install -g @minions-agents/cli
```

## Requirements

- **Node.js** 20 or later
- **Python** 3.11 or later (for Python SDK)
