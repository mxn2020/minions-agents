# Welcome to Minions Agents

We're excited to introduce **Minions Agents** — Agent definitions, runs, traces, and approval requests for the agent fleet.

## What's Included

- **TypeScript SDK**: `npm install @minions-agents/sdk`
- **Python SDK**: `pip install minions-agents`
- **CLI**: `npm install -g @minions-agents/cli`

## Getting Started

Check out the [documentation](https://agents.minions.help) for a full guide.
